# Code of Conduct

## Our standard

We want this project to remain a respectful, technically rigorous, and clinically responsible community. Participants must be constructive, inclusive, and considerate in issues, reviews, discussions, and code contributions.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, deliberate disruption, and sharing private or sensitive clinical information.

## Enforcement

Project maintainers may remove comments, reject contributions, or restrict participation when behavior violates this code. Report concerns privately to the repository maintainers through the contact method listed in the GitHub repository. Please include links, dates, and relevant context; do not include patient data or secrets.

This code is adapted from the Contributor Covenant principles and applies to all project spaces.
